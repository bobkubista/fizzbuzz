# Architecture Decision Records

One file per decision: `NNNN-kebab-title.md`, based on [template.md](template.md). Accepted ADRs are never edited except for their status line; supersede them with a new ADR.
Write an ADR when a decision is hard to reverse, affects several modules, picks a technology, defines a cross-cutting rule, or introduces a significant design pattern.
